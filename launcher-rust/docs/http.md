# http.rs — HTTP-слой

## Назначение
Единые reqwest-клиенты (пулинг соединений) и атомарные скачивания.

## Как работает
- `SHARED_CLIENT` (default UA, таймаут 30 с) и `BROWSER_CLIENT` (браузерный
  UA для optifine.net) — глобальные `LazyLock`. Все запросы идут через них.
- `download_file()` / `download_file_ua()` — атомарная запись: temp-файл
  `<dest>.part` + rename.
- `download_with_client()`: тела пишутся СТРИМОМ через `io::copy(&mut resp, …)`
  (не `resp.bytes()` — буферизация 180 МБ в RAM), пер-запрос таймаут
  20 минут (перекрывает клиентские 30 с — иначе JDK 182 МБ на 3.8 МБ/с
  обрываются на 30-й секунде «operation timed out»).
