# docs/ — документация по исходникам

Per-file документация, зеркалирующая дерево `src/` (см. скилл
docs-maintainer, `.opencode/skills/docs-maintainer/SKILL.md`).

- `CHANGELOG.md` — общая история изменений проекта.
- Обзор архитектуры и «грабли» — в `../AGENTS.md` (это не дубликат).

Обновление: автоматически при значимых правках кода + по просьбе
«обнови документацию». Секция «История изменений» в каждом файле ведётся
по каждому заходу правок.
