# Изменения проекта

## v3.0.14+ — 2026-08-17
### Изменено
- Иконка кнопки-релоада рядом с Launch снова с двумя стрелками (как у
  прежнего глифа 🔄): `assets/icons/reload.svg` заменён на заполненный
  (fill) вариант evil-icons spinner 1:1, пути масштабированы 50→24→×1.5
  (иконка занимает почти весь viewBox); размер иконки в кнопке 18→20 px.

## v3.0.13 — 2026-08-17
### Добавлено
- Кнопка «🎮 Versions» в сайдбаре над ⚙ Settings: выход из настроек в
  главный вид + открытие окна выбора версии (picker-попап). Буферы
  редактирования настроек сбрасываются через `settings_view::mark_leaving()`.
- Все иконки UI переведены с Unicode-глифов на SVG: новый модуль
  `ui/icons.rs` + `assets/icons/*.svg` (11 иконок, lucide-стиль);
  зависимость `egui_extras` (feature `svg`, resvg/usvg),
  `install_image_loaders()` в main.rs. Кнопки «иконка+текст» (сайдбар,
  Launch-кнопка, корзины) рисуются вручную `icons::icon_button()` —
  egui-`Button` принимает только текст. Глифы, которых нет в шрифтах egui
  (⟳, ✕), и эмодзи, зависящие от системы, исчезли из UI.
### Изменено
- Launch-кнопка и все иконки-глифы (☀ 🌙 🎮 ⚙ ✖ ▶ ⬇ ⚠ 🗑 🔄) заменены на
  SVG-иконки, тинтуемые цветом контекста (тема/состояние кнопки).

## v3.0.12 — 2026-08-17
### Изменено
- Настройки рендерятся в центральной области главного окна (где launch
  options и install), а не отдельной вкладкой: `ui/mod.rs` всегда
  рендерит main_view, его `CentralPanel` при `show_settings` показывает
  содержимое настроек; верхний бар/сайдбар/статус-бар/progress overlay
  остаются. Собственные панели settings_view удалены.

## v3.0.11 — 2026-08-17
### Изменено
- Launch-пикер: вместо 4 секций остались две — «Installed» и «Not
  installed». Forge и OptiFine-каталоги теперь строки внутри «Not
  installed» (vanilla + модлоадеры в одном списке); уже установленные
  Forge/OptiFine-версии не дублируются; секция «Not installed» появляется
  только при наличии содержимого.
- «Not installed» сгруппирован по MC-версии: vanilla → её Forge → её
  OptiFine одним блоком (порядок MC — как в манифесте, потом
  Forge/OptiFine-only версии; раньше были три раздельных списка).
- Forge/OptiFine-строки выглядят и ведут себя как обычные строки «Not
  installed» — selectable-кнопки с армом установки: `pending_install`
  стал kind-aware enum (`PendingInstall::Vanilla/Forge/OptiFine`), Launch
  становится «⬇ Install <label>» и клик запускает нужный установщик
  (раньше Forge/OptiFine стартовали установку сразу при клике в пикере).
  После установки авто-выбор версии ищет по `matched_installed_id()`
  (Forge/OptiFine — по ожидаемым именам папок).

## v3.0.9 — 2026-08-17
### Добавлено
- Лаунчер запоминает последнюю запущенную версию: `LastVersion` в
  `mc_console_settings.json` (опциональное поле — старые файлы грузятся),
  записывается при клике Launch (UI-поток, до спавна), восстанавливается
  как выбранный пункт при старте (`rescan_versions()` предпочитает его
  алфавитно-первой установленной версии; удалённая версия — фолбэк на
  первую).
- Launch-пикер разбит на сворачиваемые секции: Installed / Not installed /
  Forge / OptiFine (каталоги модлоадеров живут в тех же фоновых слотах
  `install_view.rs`, свёрнуты по умолчанию; выбор строки сразу запускает
  установку, как старый селектор). Поиск фильтрует все секции
  (`forge 1.20`, `optifine 1.16`).
### Исправлено
- Launch-пикер: ошибки загрузки каталогов Forge/OptiFine больше не прячутся
  за вечным «Loading…» — показывается `⚠ Forge: <ошибка>` / `⚠ OptiFine:
  <ошибка>`, фетч ретраится по троттлингу 30 с, пока пикер открыт.

## v3.0.8 — 2026-08-16
### Исправлено
- `ui/input.rs`: крестик очистки перестал зависеть от фокуса —
  `show_clear_button(buf)` без аргумента фокуса. Клик по крестику уводил
  фокус с поля (egui фокусирует нажатый виджет), крестик исчезал на кадре
  mouse-down, release терялся — «крестик есть, но клик ничего не очищает».
- Settings: поле ника больше не откатывает сохранённый ник при пустом поле
  после очистки через ✖ (`lost_focus` на кадр клика возвращал старое
  значение) — пустое поле просто не сохраняется.
- `ui/input.rs`: добавлен pointer-тест `clear_click_clears_buffer_via_pointer`
  (полный press→release через API egui 0.36: `run_ui`, кортежный
  `PointerMoved`, `modifiers`, очистка `textures_delta`); ранее такой тест не
  компилировался (API от более новой версии egui).

## v3.0.5 — 2026-08-16
### Исправлено
- Скин по нику: `--uuid` больше не нулевая константа — лаунчер вычисляет
  оффлайн-UUID как vanilla (`UUID.nameUUIDFromBytes("OfflinePlayer:"+ник)`,
  MD5 v3). Раньше нулевой UUID давал `hashCode()==0` → клиент всегда брал
  `DEFAULT_SKINS[0]` = `slim/alex` (женский скин) независимо от ника. UUID
  проверен байт-в-байт против значений, вычисленных самой игрой
  (usercache.json LAN-игроков). Инлайн-MD5 без новых зависимостей (по образцу
  SHA-1 в `install/vanilla.rs`); тот же фикс в `mc_console.ps1`
  (`Get-OfflineUUID`, легаси-файл вне git).
