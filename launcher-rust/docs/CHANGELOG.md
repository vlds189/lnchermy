# Изменения проекта

## v3.0.2 — 2026-08-13
### Исправлено
- «Install update & restart» теперь действительно перезапускает лаунчер:
  новый exe запускается автоматически, старое окно закрывается
  (`update::relaunch_after_update` + флаг `RESTART_PENDING`, проверяемый в
  `main.rs` через `ViewportCommand::Close`).

## v3.0.1 — 2026-08-13
### Исправлено
- При запуске exe больше не появляется окно консоли: добавлен
  `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]`
  (сборка была console-подсистемой — Windows создавал чёрный терминал).

## v3.0.0+ — 2026-08-13
### Добавлено
- Единый каталог установки в секции «Install»: один селектор со всеми
  вариантами Vanilla (весь манифест) + Forge (default builds) + OptiFine
  (latest builds); существующие установки помечены «(installed)».
- Лоадер и красная ошибка в попапе селектора, пока каталоги фетчатся;
  автоматический ретрай не чаще раза в 30 с.
- Селектор: параметры `none_text`, `loading`, `loading_error`.
- Селектор: виртуализация строк (`show_rows`) — полный каталог ~1000 версий
  рендерится без лагов.
### Исправлено
- Селектор: полностью убран `egui::ComboBox` (его внутренний ScrollArea давал
  второй скроллбар, уводящий searchbar) — ручная кнопка + собственный
  `egui::Popup`, на попап ровно один скролл списка, поиск закреплён.
- Селектор: кнопка растягивалась на весь интерфейс (использовался
  `ui.min_rect()` вместо rect от `allocate_space`; порядок `(Id, Rect)`).
- Селектор: фон кнопки выровнен по краю колонки, текст с отступом
  `button_padding` — как у обычных кнопок (Launch/Java).
### Изменено
- Окна выбора Vanilla/Forge/OptiFine удалены (выбор = пункт каталога);
  слоты каталогов переведены на `Result` + троттлинг 30 с.
- Install-селектор: выбор строки мгновенно запускает установку.
- `MANIFEST`: `Option<Vec<String>>` → `Option<Result<…, String>>`.

## v3.0.0 — 2026-08-13
### Добавлено
- Новый модуль `ui/selector.rs`: переиспользуемый dropdown-селектор с
  опциональными searchbar'ом (`on_search` + `search_hint`) и кнопкой
  удаления (`on_delete`).
- Автофокус поисковой строки при открытии списка селектора.
### Исправлено
- Селектор: попап больше не закрывался кликом в searchbar
  (`CloseOnClickOutside` + `ui.close()` на выборе); список фиксированной
  высоты 220 px с подписью «Empty» при нуле результатов (не сжимался и не
  скакал после очистки поиска).
### Изменено
- Launch-кнопка: выбранная версия показывается в тексте кнопки
  («▶ LAUNCH 1.20.1»).
- Выбор версии на главном экране: список кнопок → селектор (`selector`)
  с поиском и корзиной на каждую строку; заголовок «Installed versions:».
- Сайдбар: кнопки постоянного размера, текст появляется только при полном
  раскрытии (порог 108 px) — без «тряски»; свёрнутая ширина 42 → 52 px
  (симметричные отступы); единый промежуток 4 px между кнопками.

## v3.0.0 — 2026-08-12
