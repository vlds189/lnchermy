# Изменения проекта

## v3.0.0+ — 2026-08-13
### Добавлено
- Новый модуль `ui/selector.rs`: переиспользуемый dropdown-селектор с
  опциональными searchbar'ом (`on_search` + `search_hint`) и кнопкой
  удаления (`on_delete`).
### Изменено
- Выбор версии на главном экране: список кнопок → селектор (`selector`)
  с поиском и корзиной на каждую строку; заголовок «Installed versions:».
- Сайдбар: кнопки постоянного размера, текст появляется только при полном
  раскрытии (порог 108 px) — без «тряски»; свёрнутая ширина 42 → 52 px
  (симметричные отступы); единый промежуток 4 px между кнопками.

## v3.0.0 — 2026-08-12
### Изменено
- Из репозитория убрано всё, кроме `launcher-rust/` (+ `.gitignore`,
  `version.json`); `modernfix/*.nbt`, `mc_console.*`, README удалены из git
  (на диске сохранены). Корневой .gitignore: игнор всего, кроме лаунчера.
- Версия 3.0.0: `Cargo.toml`, `state.rs::APP_VERSION`, `version.json`.
- remote.origin.url очищен от захардкоженного PAT (переведён на credential
  manager).

## v2.0.0 — 2026-08-12 (сессия до v3.0.0)
### Добавлено
- Сайдбар (слева): переключатель темы и «⚙ Settings» вместо хедера;
  убрана дублирующая линия под хедером.
- Курсор-палец на всех интерактивных элементах (`interact_cursor`)
  и на крестиках модальных окон (`window_close_cursor`).
### Исправлено
- Глиф ✕ → ✖ на кнопке «Close Game» (✕ отсутствует в шрифтах egui).
- Метки версий при запущенной игре больше не подсвечиваются/не ховерятся.
- Установка Java 17/21/8: таймаут загрузки 30 с → 20 мин, стрим на диск
  вместо буферизации в RAM.
### Добавлено
- Java: ввод кастомной мажорной версии (8–100) в окне установки.
- Инлайн-результат проверки обновлений рядом с кнопкой.
