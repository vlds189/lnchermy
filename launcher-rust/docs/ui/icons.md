# ui/icons.rs — SVG-иконки

## Назначение
Все иконки интерфейса в виде SVG-файлов `assets/icons/` (11 шт., lucide-стиль:
stroke-начертание, viewBox 24, растр 256 px — нескалирующиеся штрихи
`vector-effect="non-scaling-stroke"`, чтобы иконки оставались чёткими при
любом DPI). Модуль задевает ассеты в бинарник (`egui::include_image!`),
растеризует их через `egui_extras` SvgLoader (resvg/usvg) и отдаёт в UI как
виджеты или текстуры.

## Как работает
- Ассеты монохромные — **белые на прозрачном**: egui при отрисовке умножает
  текстуру на тинт-цвет (вершинный цвет шейдера × тексель), а чёрный тексель
  под любым тинтом остался бы чёрным. Белые же иконки перекрашиваются без
  остатка, поэтому тёмная/светлая темы и цветные кнопки не требуют
  отдельных файлов.
- `install_image_loaders(&cc.egui_ctx)` — один раз при старте (main.rs).
- `widget(source, size)` / `tinted(source, size, color)` — `Image`-виджет
  фиксированного размера (для `ui.add(...)`, неинтерактивные места).
- `texture(ctx, source, size) -> Option<TextureId>` — текстура для painter'а
  (крестик TextInput, кнопки): `Image::load_for_size` + `TexturePoll::Ready`.
  SvgLoader кэширует результат по (uri, SizeHint) — повторные вызовы кадра
  бесплатны, первый вызов синхронный (байты встроены).
- `icon_button(ui, source, icon_size, min_size, text, fill, enabled) ->
  Response` — кнопка «иконка ± текст», нарисованная вручную: egui-`Button`
  принимает только текст (`WidgetText` без варианта Image), поэтому иконки
  в кнопках рисуются painter'ом по тем же визуалам, что у Button
  (bg/stroke/hover/active/inactive через `ui.style().interact`), как
  combo-кнопка в `ui/selector.rs`. `fill` — цвет фона (состояния Launch).
  Кнопка реализована как `egui::Widget` и добавляется через
  `Ui::add_enabled(enabled, …)`: disabled-состояние регистрируется штатно
  (флаг `ENABLED` у Response), поэтому `clicked()` всегда ложь, визуалы —
  inactive, тултипы через `on_disabled_hover_text` и полупрозрачность при
  неактивности — как у настоящего `egui::Button`.

## Где применяется
Сайдбар (тема/геймпад/настройки), Launch-кнопка (play/close/warning/
download/loading), кнопка-релоад пикера, корзины в пикере и селекторе,
hint-ошибки каталогов (warning), радио темы в настройках (moon/sun),
крестик очистки TextInput (close).

## История изменений
### 2026-08-17 — v3.0.13
- Модуль создан: все Unicode-глифы интерфейса (☀ 🌙 🎮 ⚙ ✖ ▶ ⬇ ⚠ 🗑 🔄 ⟳)
  заменены на SVG-ассеты; добавлена зависимость `egui_extras` (feature
  `svg`, resvg/usvg). Кнопки «иконка+текст» — ручная отрисовка
  `icon_button()` (в шрифтах egui нет ⟳/✕, эмодзи выглядят по-разному на
  разных системах).
- `icon_button` переведён на `Ui::add_enabled` + `impl Widget`: disabled
  теперь регистрируется штатно (без `Sense::hover`-финта), работает
  `on_disabled_hover_text`; кнопка-релоад пикера больше не гейтится
  `enabled` (остаётся активной при отсутствии выбранной версии — иначе
  пикер не открыть).
- Ассеты перекрашены из чёрных в белые: egui умножает текстуру на тинт
  (вершинный цвет × тексель), чёрный оставался бы чёрным под любым цветом
  — иконки на новой test-сборке выглядели полностью чёрными.
