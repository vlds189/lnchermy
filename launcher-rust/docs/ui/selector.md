# ui/selector.rs — переиспользуемый селектор

## Назначение
Готовый dropdown-селектор (кнопка в стиле ComboBox + собственный
`egui::Popup`) с опциональным searchbar'ом, кнопкой удаления и состояниями
загрузки. Внутренний компонент, не привязан к версиям Minecraft — клиенты
передают свои данные через колбэки.

## Как работает
- `SelectorItem = (String, String)` — `(id, label)`: `id` — машинное значение
  (возвращается в колбэки), `label` — что видит пользователь (может содержать
  тег, например «1.20.1  [Forge]»).
- `selector(ui, id, items, selected_idx, enabled, on_delete, on_search,
  search_hint, none_text, loading, loading_error)`:
  - `selected_idx: &mut Option<usize>` — индекс в исходном `items`; обновляется
    при выборе. Клиент мапит индекс на свои данные.
  - `enabled: false` — кнопка и опции grey-out (`Sense::hover` вместо
    `Sense::click`, visuals `inactive`), попап не открывается (игра запущена).
    Специфичный тултип «Close the running game first» зашит в компонент.
  - `on_delete: Option<&mut dyn FnMut(usize, &str)>` — если `None`, корзина
    не рендерится вообще; если `Some` — у каждой строки появляется кнопка-
    корзина (SVG-иконка trash из `ui/icons.rs`, `icon_button()`), клик
    вызывает колбэк с `(индекс в items, id)` и НЕ меняет выбор.
  - `on_search: Option<&mut dyn FnMut(&str) -> Vec<SelectorItem>>` — если
    `Some`, над списком рисуется TextEdit; фильтрация — колбэк: строка
    запроса → отфильтрованные `(id, label)`. Пустой запрос → показываются
    все `items`, колбэк не вызывается. Отфильтрованные строки обратно
    сопоставляются с исходным `items` по `id`, поэтому `selected_idx`
    и индексы в `on_delete` остаются стабильными.
  - `search_hint: Option<&str>` — placeholder поиска при пустом поле;
    `None` → «Search…».
  - `none_text: Option<&str>` — текст кнопки при `selected_idx == None`
    (например «Install type…»); `None` → пустая кнопка.
  - `loading: true` — вместо списка спиннер + «Loading…» (данные ещё
    фетчатся), searchbar скрыт.
  - `loading_error: Option<&str>` — красная подпись под спиннером (например,
    сбой фетча, который будет ретраиться); слева от текста — SVG-иконка
    warning, затинтированная в красный.
- **Почему не `egui::ComboBox`:** ComboBox оборачивает содержимое в свой
  собственный ScrollArea — вместе с нашим скроллом списка появлялся второй
  скроллбар на всю высоту попапа, который при скролле уводил searchbar.
  Вместо этого — ручная кнопка (фон `ui.painter().rect` + галея текста +
  треугольник ▼) и `egui::Popup::menu`: внутри ровно один ScrollArea на
  списке, поиск закреплён вне скролл-зоны и физически не может уехать.
- Кнопка по раскладке совпадает с ComboBox: `allocate_space` берёт
  `галея + иконка + 2·button_padding`, фон выровнен по краю колонки, текст
  утоплен на `button_padding` — как у обычных кнопок egui (Launch/Java).
  ВАЖНО: `allocate_space` в egui 0.36 возвращает `(Id, Rect)`; использовать
  `ui.min_rect()` нельзя — кнопка растянется на весь родитель.
- Запрос поиска хранится в `ctx.data()` (temp-data, ключ
  `id.with("search_query")`): компонент без собственного состояния, но
  строка переживает кадры, пока попап открыт.
- Попап: `.close_behavior(CloseOnClickOutside)` — дефолт `CloseOnClick`
  закрывал список от клика в любом месте, включая searchbar; выбор закрывает
  попап вручную (`ui.close()`). Клик по кнопке — toggle (обрабатывает сам
  `Popup::menu`).
- Список опций — фиксированная высота 220 px (`LIST_H`): `max_height` +
  `min_scrolled_height` + `auto_shrink(false)` (виджет всегда ровно 220 px,
  даже при паре строк — попап не прыгает). Пустой результат → серая
  подпись «Empty» той же высоты. Строки виртуализированы `show_rows`
  (собираются только видимые) — каталог из ~1000 версий рендерится плавно.
- Автофокус searchbar при открытии: переход закрыто→открыто ловится
  `Popup::is_id_open(ctx, id.with("popup"))` по состоянию памяти прошлого
  кадра (на кадре клика попап ещё «закрыт»), затем `request_focus()`.
- `egui::Button::selectable` вместо отдельного виджета: в egui 0.36
  `SelectableLabel` удалён из публичного API (см. AGENTS.md, gotchas).

## История изменений
### 2026-08-17 — v3.0.13
- Корзина строк и иконка ошибки загрузки переведены на SVG (`icons::TRASH`,
  `icons::WARNING`); кнопка-корзина — `icons::icon_button()` (disabled-состояние
  — inactive-визуалы, как у обычной кнопки).
### 2026-08-13 — v3.0.0
- Полностью убран `egui::ComboBox` (давал второй скроллбар, уводящий
  searchbar): ручная кнопка + собственный `egui::Popup::menu`; на весь попап
  один ScrollArea списка, поиск закреплён.
- Кнопка выровнена с обычными кнопками: фон по краю колонки, текст с
  отступом `button_padding`; исправлено использование `ui.min_rect()`
  (кнопка растягивалась на весь родитель) и порядка `(Id, Rect)` из
  `allocate_space`.
- Новые параметры: `none_text`, `loading`, `loading_error`.
- Строки виртуализированы (`show_rows` + `auto_shrink(false)`): полный
  каталог ~1000 версий без лагов, высота списка стабильна при фильтрации.

### 2026-08-13 — v3.0.0
- Создан компонент: `selector()` с опциональными `on_delete`, `on_search`,
  `search_hint`. Вынесен из инлайнового ComboBox в `version_list_section`.
- Попап: `CloseOnClickOutside` + `ui.close()` на выборе (клик в searchbar
  больше не закрывал список).
- Список фиксированной высоты 220 px + «Empty» при нуле результатов
  (высота не сжималась и не возвращалась скачком после очистки поиска).
- Автофокус поисковой строки при открытии попапа.
